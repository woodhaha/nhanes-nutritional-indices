# Dietary Inflammatory Index and Memory Function: Population-Based National Sample of Elderly Americans

- **Authors**: Emily Frith, Paul D. Loprinzi
- **Year**: 2018
- **Journal**: British Journal of Nutrition, 119(5)
- **DOI**: 10.1017/S0007114517003804
- **Data**: NHANES 2011-2014, adults 60-85 (n=1,723)

## Key Findings
- DII inversely associated with all memory parameters
- Episodic memory (CERAD): β=-0.39 (95%CI -0.79, 0.00)
- Semantic memory (AF): β=-1.18 (95%CI -2.17, -0.20)
- Executive function/working memory (DSST): β=-2.80 (95%CI -5.58, -0.02)
- DII not associated with CERAD-delayed recall
- Consistently inverse: higher DII → worse performance

## Relevance to Our Study
Early NHANES 2011-2014 DII+cognition paper. Smaller sample than Feng (2022). Establishes baseline DII-cognition association. Only examined DII, no other nutritional indices.
