# NHANES Nutritional Indices Cross-Cancer Analysis

Analysis code for manuscript submitted to Clinical Nutrition.

Manuscript: PNI, CONUT, and GNRI predict all-cause mortality across 5 cancer types with in-depth GI validation (NHANES III + Continuous NHANES, N=2,942).

## Files
- `manuscript.tex` — LaTeX manuscript source
- `supplementary.tex` — Supplementary materials
- `references.bib` — 26 references
- `07_pancancer_analysis.R` — Main analysis pipeline
- `06_pancancer_prep.R` — Data preparation
- `flow_diagram.R` — CONSORT-style flow diagram

## Data
Publicly available at https://www.cdc.gov/nchs/nhanes/
